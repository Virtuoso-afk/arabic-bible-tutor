# PD-004 design rationale

**Status:** proposed final synthesis for product-owner and Maestro visual review. PD-004 approves the A+B+C synthesis direction; the exact `نَسَق` identity, tokens, copy, and compositions in these proofs are not approved production specifications until this review is accepted.

## Decision

PD-004 combines Concept A's product foundation, Concept B's learning energy, and selected Concept C study patterns into one system. The synthesis uses A's spacing, hierarchy, light learning surfaces, responsive shell, and maintainable component model as the structural base. B supplies the brand rhythm, course journey, warm milestone colors, evidence-backed achievements, and restrained completion energy. C supplies the reading measure, source metadata, marginal guidance, citations, and explicit labels for source, educator guidance, interpretation, and generated explanation.

The result is intentionally not a visual collage. All retained patterns are redrawn with one palette, type system, radius scale, border language, icon style, and interaction grammar.

## Product personality

- **Clear:** the current objective and next action lead each learning surface.
- **Energizing:** course journeys and earned milestones make movement visible without pressure.
- **Studious:** source context and content layers are legible and reviewable.
- **Warmly professional:** light surfaces, confident navy, and limited bright accents avoid both austerity and childishness.
- **Extensible:** path accents and content-layer labels are configuration, not Bible-specific branding.

The provisional identity is **`نَسَق`**, referring to coherent order, progression, and the relationship among learning steps. The path-and-nodes mark visually joins structure with movement. It is a review device and requires separate naming, trademark, linguistic, and owner approval.

## Coherence rules

1. Navy and white establish the product, while blue owns interaction. Teal and plum identify paths only; lime and coral appear at meaningful route moments.
2. Every card uses the same border, radius, shadow, and spacing scales. Path cards differ through a top rule, icon, label, and content.
3. The route, progress bars, and achievements all describe evidence. None grant currency, rank, loss protection, or social status.
4. The tutor uses the same content-layer labels as the lesson. It never becomes the page's primary destination.
5. Editorial elements appear only when source literacy matters. Future subjects can use equivalent labels such as dataset, worked example, instructor note, and generated explanation.
6. Mobile reduces columns and persistent navigation before reducing text size or learning context.

## Path separation

The two initial paths share the shell, card system, lesson frame, tutor orchestration, route visualization, and system states. They retain separate configuration:

| Concern | Path A — Arabic language | Path B — Bible study in Arabic |
| --- | --- | --- |
| Accent | Teal plus visible “المسار A” label | Plum plus visible “المسار B” label |
| Progress | Vocabulary, structure, comprehension, expression | Context, source use, evidence, interpretation literacy |
| Exercise grammar | Language production and comprehension | Source/context/evidence reasoning without grading belief |
| Tutor mode | Language coach using approved lesson references | Study tutor using the course's source and interpretive boundaries |
| Completion evidence | Language-skill evidence | Study-competency evidence |

Color never carries path meaning alone. No progress value transfers between paths.

## Disclosures and limitations

- All copy and exercises are original demonstration material. The proof shows a reference but no Bible passage.
- “Saved,” progress, tutor, and feedback states are deterministic simulation. There is no persistence, AI, evaluation service, or account.
- The identity and final tokens require owner approval. User testing, educator review, and legal permission are not claimed.
- Dark-mode behavior is specified but not visually approved by these light-theme proofs.
